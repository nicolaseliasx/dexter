# Translations

D.EX.T.E.R. ships in **English only**. `en.json` is the single source of strings.

The upstream Termix translations (`translated/`) and their `translations-lock.json` were removed from this fork, and `languages.json` is an empty list, so the language pickers show only English. To bring a language back, restore its file under `translated/` from Termix and add it to `languages.json`.
