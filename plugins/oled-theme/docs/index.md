# OLED Theme

Adds an **OLED** entry to Settings > Appearance > Theme (and its quick swatches). The workspace and the terminal are pure `#000000`; the sidebar and cards are `#080808`/`#0a0a0a`, separated by `#1f1f1f` borders. Hover and selected rows use `#1f1f1f`.

Install with **Install from file** and enable the plugin. Turning it off makes a saved OLED choice fall back to System.

Limit: classes tied to the `dark:` variant (small input tints) apply only under the built-in Dark theme, as for any plugin theme.
