# Custom CSS

Cole CSS nas configurações de usuário deste plugin e salve. Os estilos são
aplicados à sua interface e aos elementos renderizados posteriormente.

Desative **Aplicar CSS personalizado** para voltar ao visual normal sem apagar
o CSS. Se um estilo impedir o acesso às configurações, adicione
`?custom-css=off` ao endereço do Termix e recarregue a página; com parâmetros
existentes, use `&custom-css=off` antes do fragmento `#`.

Consulte o [README](../README.md) para instalação, exemplo, limites e testes.
